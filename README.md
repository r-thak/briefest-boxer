# Briefest Boxer

Client-side aiming guide for Minecraft Java Edition. Every listed loader target includes a camera-based reachable-surface highlight for visible entities; renderer implementations vary by Minecraft version. The highlight is clipped to the entity's hittable bounds and interaction reach. On version 26.2, the mod also previews an adult Sulfur Cube's predicted motion using its absorbed body-item archetype and the player's held weapon, attack state, and aim angle.

The target list covers established modded release hubs rather than every patch release. Legacy Fabric supplies older targets. Forge builds are included where requested; NeoForge projects are excluded from the release script and bundle.

Version 0.1.0 distributable jars are collected in [`releases/0.1.0`](releases/0.1.0), with SHA-256 hashes in `SHA256SUMS`. Install only the jar matching both your Minecraft version and loader. These are locally built artifacts; they have not been published to a mod hosting site. Run [`scripts/build-releases.sh`](scripts/build-releases.sh) to clean-build the loader/version matrix and refresh the bundle. The build matrix uses Java 8 for 1.8.9, Java 17/21 for later targets, and Java 25 for 26.2; set `BRIEFEST_BOXER_JAVA8_HOME`, `BRIEFEST_BOXER_JAVA17_HOME`, `BRIEFEST_BOXER_JAVA21_HOME`, and `BRIEFEST_BOXER_JAVA25_HOME` if those JDKs are not discoverable.

The 26.2 Fabric client game test includes Sodium by default. From `versions/26.2/fabric`, run `../../../gradlew runClientGameTest --offline -PwithoutSodium` to run the same test without Sodium.

## Install and use

These are client-side mods. Put the matching jar in the Minecraft instance's `mods` folder and launch that same Minecraft version with the listed loader. Fabric versions that declare Fabric API as a dependency also need the matching Fabric API release. Forge jars require Forge for their exact Minecraft version.

In a multiplayer world, each build selects the nearest visible entity from the camera position and renders only the portion of its hittable bounds within interaction reach. The highlight grows or shrinks as the entity moves relative to reach. Target selection has a small distance hysteresis to prevent rapid switching between nearly equidistant entities. Older renderers use world depth testing; the 26.2 cover overlays the entity model and checks each patch against block collision shapes, allowing visibility through non-colliding foliage. Player and other-entity toggles, scan range, and colors are configured in `config/briefest_boxer.properties`; on 26.2 Fabric, the same settings are available from the Mods screen through Mod Menu 20.0.3 or newer. On 26.2, aiming at an adult Sulfur Cube shows a slim, translucent predicted path with an enlarged endpoint marker. The default preview horizon is 256 ticks (12.8 seconds), with shorter and longer choices in the config. The flight prediction clips the cube's swept hitbox against the world's block collision shapes and models ground friction, bounce, and water travel. Cubes without a body item use vanilla knockback; equipped cubes use their matching archetype knockback, with held-weapon damage, knockback effects, attack-direction angle rotation, and aim-height transfer. A short target grace period prevents one-frame aim-result changes from flickering the path. The estimate also uses the cube's current motion and the player's attack cooldown and aim angle. It is client-side and does not require other players to install the mod.

## Architecture

The project is split into version-specific loader adapters and shared, loader-independent aiming/prediction logic. Adapters own entity/model queries, rendering hooks, attack-attribute lookup, and version-specific Sulfur Cube physics access. Older builds must not ship cube-specific code or references.

## Current status

Fabric adapters for 1.6.4 through 26.2 and Forge adapters for 1.7.10 through 26.2 build and package. A clean run of the complete Fabric/Forge release matrix succeeded. All renderer families use camera-based reachable-surface shading; the oldest Legacy Fabric clients use a GameRenderer mixin and fixed-function OpenGL, while newer versions use their loader's world-render events or game gizmo renderer. The 26.2 render commands are retained briefly and refreshed every frame; without an expiration time, Minecraft discards them before drawing. The 26.2 surface mesh batches its geometry to reduce per-frame overhead. The 26.2 Fabric game tests create adult size-2 Sulfur Cubes and generate the configured 256-step forecast. They compare launch velocity against real server-side hits for absorbed and empty cubes, then track all 256 flight ticks within 30 cm across 12 absorbed materials in an arena with floor and wall collisions. An adult oak-log cube's submerged and dry-to-water paths are compared against 24 real server ticks, with the dry-to-water path staying within 3 cm in the contained-pool test. A same-material, same-weapon upper/lower aim pair verifies that looking at different vertical parts changes launch height. The adult oak-log case leaves normal steering and jumping goals active; per-archetype cases disable goals to isolate material and collision physics. The adult-cube client test advances normal world ticks, waits for the client entity update, requires a real forward hit impulse and at least 0.75 blocks of client-side displacement, and captures a labeled before/after screenshot pair from a fixed camera. A separate client game-test opens the Briefest Boxer configuration screen through Mod Menu and verifies all eight settings controls at the game UI scale. The Fabric 26.2 dev client registers Briefest Boxer while co-loading Sodium 0.9.2-alpha.4 and Mod Menu 20.0.3; the Forge 26.2 dev client also initializes the mod. Shared-core tests cover coverage near the reach boundary, hitbox and reach bounds, wall-collision clipping, vanilla knockback for empty cubes, and ground friction. Forge 26.2 development uses ForgeGradle's merged source-set setting and a macOS first-thread JVM flag; its launcher was run with Java 25 for the game. The 1.21.1 Forge development run now merges resources with compiled classes, and its runtime log confirms the mod class is loaded. OptiFine HD U J1 lists Forge 52.0.16 for Minecraft 1.21.1 ([official OptiFine downloads](https://optifine.net/downloads)). A production-style isolated Forge 52.0.16 client with OptiFine HD U J1 reaches Forge's render thread: its logs show OptiFine selecting 425 transform targets, Forge discovering the Briefest Boxer jar, reloading mod resources, and OptiFine stitching the texture atlases. OptiFine warns that it does not recognize Forge's delegated mod-resource pack; rendering the highlight in a live world with OptiFine remains unverified. The 26.2 trajectory estimate models the cube's separate default-damage and player-knockback impulses, held-weapon modifiers, absorbed-item archetype attributes, post-attack horizontal damping, attack cooldown, critical hits, sprint knockback, existing cube motion, block friction, collisions, and bounce. Effects that cannot be resolved from client-side state remain estimates.
